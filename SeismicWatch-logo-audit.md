# SeismicWatch Logo and Icon Audit

## Executive summary

SeismicWatch does not have just one logo. Its source tree contains a Play Store master image, a default adaptive launcher icon, five theme-selectable launcher variants, a richer in-app brand mark, an animated splash mark, a monochrome notification/Quick Settings glyph, and legacy raster launcher fallbacks.

The most important finding is that the launcher normally shown to users is **Deep Ocean** (`ic_launcher_deepocean.xml`). Although the application element declares `@mipmap/ic_launcher`, the enabled launcher activity alias overrides it with the theme-specific drawable. Deep Ocean is enabled by default and is also the default theme.[1][2]

## What should not be treated as a separate logo

- Files beneath `F:\Laptop-Projects\SeismicWatch\app\build\intermediates\packaged_res` are generated build copies. The files under `app\src\main\res` are authoritative.
- `ic_seismic_wave.xml` is deliberately monochrome because Android small-notification icons are masks; it should not replace the full launcher/store artwork in portfolio presentation.
- The splash animation and `ic_logo.xml` are related brand marks, but they serve different contexts and should not be confused with the installed launcher icon.

## Technical gap found

The two adaptive launcher XML files contain background and foreground layers but no `<monochrome>` layer. Based on the audited source, Android 13+ themed-icon support is therefore not explicitly implemented for the default adaptive icon. The activity-alias theme launchers are ordinary full drawable compositions rather than complete adaptive-icon resource sets, so masking and themed-icon behavior may differ between launchers/OEMs. This is an inference from the resource definitions, not evidence of a runtime failure.

## Recommended asset choice

1. **Portfolio/project-card logo:** `app\src\main\res\drawable\ic_launcher_deepocean.xml` (default installed identity), rendered to PNG if the portfolio requires a raster file.
2. **Store-quality marketing logo:** `ic_launcher-playstore.png`.
3. **Expanded branding/gallery asset:** `app\src\main\res\drawable\ic_logo.xml`.
4. **Do not use as the main logo:** `ic_seismic_wave.xml`, because it is the notification/service glyph.
