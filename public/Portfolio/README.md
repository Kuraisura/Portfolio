# Portfolio Images

Please add your project images to this folder with the following names:

## Required Images:
- `profile.jpg` - Your profile photo (recommended: 512x512px, square)
- `STIRams.jpg` - STI RFID Attendance project screenshot
- `FacialRecognition.jpg` - Facial Recognition System screenshot
- `StBenedict.jpg` - St. Benedict HMS screenshot
- `Raiko.jpg` - Raiko E-Commerce screenshot
- `JournalEase.jpg` - JournalEase app screenshot
- `PetHaven.png` - Pet Haven screenshot
- `YoutubeToMP4&MP3.png` - YT Converter screenshot

## Image Guidelines:
- Use high-quality images (minimum 1920x1080 for project screenshots)
- Profile photo should be square (1:1 aspect ratio)
- Keep file sizes optimized (under 500KB per image)
- Use JPG for photos, PNG for screenshots with transparency
- Make sure images are well-lit and clearly show your projects
